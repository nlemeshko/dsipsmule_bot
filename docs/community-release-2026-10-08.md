# Обновление игр и настроений от 8 октября 2026

Первоначальный код: коммит `14c8e56`, 114 тестов пройдено.
Голосование `/mood` редактирует сообщение; каталог содержит 60 песен и 10 настроений.

При первом развёртывании GitHub отклонил push: доступная HTTPS-авторизация и SSH-ключ относились к
`mlemeshko-fc`, у которого нет прав записи в `nlemeshko/dsipsmule_bot`.
Позже коммиты опубликованы; доступ восстановлен через SSH-ключ владельца
репозитория. Основной способ развёртывания снова GitHub Actions/Helm.

Первоначально обновление было установлено непосредственно в Kubernetes, context
`mdsn`, namespace `smule-bot`, Deployment `smule-bot`. Базовым образом был
`ghcr.io/nlemeshko/dsipsmule_bot:1.1.8`.
Неизменяемый ConfigMap `smule-bot-community-14c8e56` смонтирован через volume
`community-source` с `subPath` в четыре файла:

- `/app/commands/fun.py`
- `/app/services/fun.py`
- `/app/services/fun_catalog.py`
- `/app/storage/fun.py`

Pod template содержит аннотацию `smule-bot/community-source: 14c8e56`.
В таком режиме файлы сохраняются при замене pod. Стратегия Deployment — `Recreate`.
Пользовательские данные остаются в существующем S3-хранилище.

После восстановления записи в GitHub отправьте коммиты в `master`, дождитесь
сборки образа и успешного развёртывания. Затем уберите четыре `volumeMounts`
с именем `community-source`, соответствующий volume и аннотацию из Deployment,
чтобы будущие образы использовали собственные файлы. Проверьте готовность pod
и наличие 60 песен и 10 настроений перед удалением ConfigMap.
До снятия монтирований эти четыре файла имеют приоритет над файлами образа.

В последующее обновление включены приоритет активных игр перед AI, запрет AI-ответов
на цитаты игровых сообщений после завершения игры и случайные комментарии с
вероятностью 10% по умолчанию. Разговор продолжается по цитате/ответу на сообщение
бота вне игры; слово «Бот» само по себе не вызывает гарантированный ответ.
Ответы в чужих диалогах не выбираются для случайного комментирования.
Все 118 тестов пройдены, включая цитирование подсказки и победный ответ в «Поле чудес».

Для отката этого обновления снимите те же монтирования, volume и аннотацию:
бот вернётся к коду базового образа после замены pod. Не удаляйте ConfigMap,
пока он используется Deployment.
