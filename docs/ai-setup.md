# Бесплатные AI-функции: Groq + Cloudflare

Groq отвечает на вопросы и расшифровывает речь, Cloudflare Workers AI создаёт
картинки. Бот обращается к их HTTPS API напрямую: новые серверы, GPU, Workers
и изменения Ingress не нужны. Бесплатные тарифы имеют лимиты; не подключайте
платные планы для этого варианта. При лимите бот сообщает об ошибке и не переключается
на другие сервисы, не повторяет запросы автоматически.

## Настройка аккаунтов

1. Зарегистрируйтесь в [Groq Console](https://console.groq.com/keys) и создайте API-ключ.
   Оставьте бесплатный тариф. Конкретные ограничения доступны в разделе Limits.
2. В [Cloudflare Dashboard](https://dash.cloudflare.com/) откройте **Workers AI → Use REST API**.
   Нажмите **Create a Workers AI API Token**, создайте токен и скопируйте его.
   Там же скопируйте **Account ID** (32 шестнадцатеричных символа).
   Если создаёте токен вручную, нужны права **Workers AI – Read** и **Workers AI – Edit**
   для вашего аккаунта. Переносить домен в Cloudflare не требуется.
3. В Lens отредактируйте существующий Secret `env` в namespace `smule-bot`.
   Сохраните остальные ключи и добавьте:

   | Ключ | Значение |
   | --- | --- |
   | `GROQ_API_KEY` | API-ключ Groq |
   | `CLOUDFLARE_API_TOKEN` | Токен Workers AI |
   | `CLOUDFLARE_ACCOUNT_ID` | Account ID Cloudflare |
   | `ALLOWED_GROUP_ID` | ID разрешённых Telegram-групп через запятую |
   | `AI_REPLY_PROBABILITY` | `1.0` — временно 100% ответов; `0.1` — вернуть 10% |

   Если редактируете YAML вручную, обычные строки вводите в `stringData`;
   в `data` Kubernetes ожидает Base64. Не заменяйте весь Secret новым файлом с тремя ключами.
4. Соберите и разверните **новый образ бота** обычным GitHub Actions/Helm workflow.
   Helm уже подключает Secret через `envFrom`. Обычный перезапуск старого образа
   не установит новую функциональность. После будущих изменений ключей достаточно
   заменить Pod; Secret автоматически не обновляет переменные запущенного контейнера.
5. Для случайных ответов на обычные сообщения отключите Privacy Mode у бота:
   **@BotFather → /setprivacy → ваш бот → Disable**. Если Telegram по-прежнему не
   доставляет сообщения, повторно добавьте бота в группу. Дополнительные права
   администратора для этого не нужны.

## Проверка

- В личке или мини-приложении: `/ask Придумай короткое приветствие для Smule`.
- `/draw Кот с гитарой в золотом свете`. Русские описания автоматически переводятся
  через Groq на английский с сохранением смысла; подпись в приложении остаётся исходной.
  Если Groq не подключён или перевод недоступен, используется исходное описание.
- Отправьте личное голосовое в Telegram: бот вернёт текст.
  Поддерживаются OGG, MP3, WAV, M4A, WebM и другие поддерживаемые Groq форматы;
  аудио ограничено 10 минутами и 20 МБ. Расшифровка доступна в Telegram.
- В разрешённой группе новые голосовые расшифровываются автоматически;
  `/transcribe` ответом на аудио запускает расшифровку явно.
  Расшифровывается каждое новое голосовое независимо от отправителя: обычного
  пользователя, анонимного администратора, канала или подставного пользователя Telegram,
  в том числе новые пересылки. Активная игра не мешает расшифровке; настройка вероятности
  относится только к автоматическим ответам на текст. Последовательные голосовые
  не отсекаются ограничением 5 секунд, повторная доставка того же сообщения пропускается.
  Разрешённой должна быть группа-получатель (`chat_id` в `ALLOWED_GROUP_ID`).
  Старые голосовые и правки пропускаются. Лимиты Groq и ограничения размера
  и длительности аудио продолжают действовать.
- На **новые обычные текстовые сообщения** в разрешённых группах бот отвечает
  с вероятностью **100%** по умолчанию, без пауз между автоматическими ответами.
  Бот представляет себя как злобный, матюкливый бот Ведьмака — певца из Smule;
  отвечает коротко, по-русски, с матом, сарказмом и чёрным юмором по смыслу сообщения.
  Лимиты API продолжают действовать.
  Для возврата к 10% задайте `AI_REPLY_PROBABILITY=0.1` в Secret `env` и замените Pod;
  в этом режиме снова действуют паузы 15 секунд на группу и 5 секунд на пользователя.
  `0` отключает случайные комментарии, сохраняя обращения к боту, расшифровку голосовых и `/ask`.
  Ходы активной игры, команды, сообщения ботов, каналы, правки и очередь сообщений,
  созданных до запуска бота, пропускаются. Сообщения старше 5 минут также пропускаются.
- Обращения, начинающиеся со слова **«Бот»** (без учёта регистра, например «Бот, объясни»),
  и ответы/цитаты на сообщения именно этого бота вызывают ответ независимо от
  `AI_REPLY_PROBABILITY` и пауз случайного комментирования, в том числе во время игры.
  При ответе на сообщение бота нейросеть получает его текст или выбранную цитату как контекст.
  Действуют прежние проверки разрешённой группы и новизны; повторная доставка не даёт второй ответ.
- Анонимные голосовые в состоянии «Анонимка» отправляются на модерацию.
  Обычные текстовые сообщения в личке идут в Groq, если ключ настроен;
  активные формы и игры сохраняют своё поведение.

Модели можно переопределить в Secret через `GROQ_TEXT_MODEL` и `GROQ_SPEECH_MODEL`.
По умолчанию используются `openai/gpt-oss-20b` и `whisper-large-v3-turbo`.
Картинки: `@cf/black-forest-labs/flux-2-klein-4b`, 1024×1024, фиксированные 4 шага.
Настройка `CLOUDFLARE_IMAGE_MODEL` в Secret позволяет выбрать Klein 9B
(`@cf/black-forest-labs/flux-2-klein-9b`) или прежнюю Schnell
(`@cf/black-forest-labs/flux-1-schnell`). Обновление модели по умолчанию требует
нового образа; явно заданная в Secret модель имеет приоритет.

По [тарифам Cloudflare](https://developers.cloudflare.com/workers-ai/platform/pricing/#image-model-pricing)
Klein 9B расходует около 1364 Neurons на картинку 1024×1024 — примерно 7 картинок
на бесплатные 10 000 Neurons в сутки. Klein 4B расходует около 104 Neurons —
примерно 95 картинок. Расчёт предполагает, что вся квота используется только
для генерации изображений. Новая модель и перевод не гарантируют идеальный
результат для каждого запроса.

Голосовой ответ нейросети
не включён: голос здесь используется для расшифровки входящих сообщений.
