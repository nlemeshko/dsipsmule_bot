# DSIP Smule Bot - Полнофункциональный Telegram бот

Ведьмак — Telegram бот сообщества DSIP Smule. Официальный сайт: [dsipsmule.one](https://dsipsmule.one).

## Telegram Mini App

Все функции доступны в мобильном мини-приложении: анонимки с фото и голосом,
предложения песен, оценка и промо, песня дня, предсказания, игры, AI-вопросы,
зал славы, номинации, голосование и личные беседы.
Интерфейс оформлен в тёмно-коричневых и золотых оттенках; баннер и нижняя ссылка
ведут на официальный сайт сообщества.

`/start` и `/app` отправляют кнопку приложения; при запуске бот устанавливает
кнопку «Открыть приложение» в меню Telegram. Telegram требует нажатия пользователя
и не позволяет боту автоматически открыть приложение после команды.
Команды в группах и существующая модерация продолжают работать.

### Запуск мини-приложения

```env
MINI_APP_URL=https://bot.dsipsmule.one
MINI_APP_HOST=0.0.0.0
MINI_APP_PORT=8080
MINI_APP_AUTH_MAX_AGE=3600
```

Установите `requirements.txt` и запустите `python bot.py`: polling бота и HTTP-сервер
работают в одном процессе. HTTPS-прокси должен направлять `/` и `/api/*` на порт
8080. В Docker опубликуйте этот порт. Без `MINI_APP_URL` используется старое меню.
Токен бота и ключи API остаются на сервере. API проверяет подпись Telegram initData,
срок сессии и владельца вложения. Через час приложение нужно переоткрыть.

Helm уже содержит Service на 8080 и Ingress для `bot.dsipsmule.one`; TLS использует
Secret `bot-dsipsmule-one-tls`. Настроены Nginx, ClusterIssuer `letsencrypt-prod-dns`
и HTTPS-редиректы. Cert-manager создаёт сертификат для `bot.dsipsmule.one` по
аннотации Ingress. DNS должен указывать на ваш ingress-контроллер. Для фото и
аудио задан лимит 21 МБ, для голосовых ответов — таймауты 180 секунд.

Дополнительно можно включить Main Mini App в BotFather и указать тот же URL,
чтобы приложение открывалось кнопкой из профиля бота.

Ответы, изображения, проигрыватели аудио и шаги заявок отображаются внутри
приложения. Загруженные пользователем вложения также отправляются в личный чат
с ботом: Telegram присваивает им file_id для существующей модерации. Незавершённые шаги доступны и в приложении, и в чате; действия одного
пользователя выполняются последовательно.

Каждое новое действие заменяет предыдущий результат в интерфейсе. Состояния
заявок и игр сохраняются между шагами; переход к другой функции запускает её
сценарий. Иллюстрации форм отображаются сразу при открытии раздела.
Текущий результат и состояния игр находятся в памяти одного процесса; при
перезапуске они сбрасываются. Результат содержит до 60 ответов, вложения
хранятся до 30 минут в ограниченном кэше. Зал славы сохраняется в CSV. Используйте одну реплику: polling и состояния не поддерживают несколько
независимых процессов. Для сохранения зала славы задайте `DATA_DIR` с доступной
для записи директорией; в Helm это автоматически делает включённый PVC.

## Установка

### 1. Клонирование и настройка

```bash
# Перейдите в директорию проекта
cd smule-bot

# Активируйте виртуальное окружение
source venv/bin/activate

# Установите зависимости (если еще не установлены)
pip install -r requirements.txt
```

### 2. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен

### 3. Настройка переменных окружения

Скопируйте файл `env.example` в `.env` и заполните его:

```bash
cp env.example .env
```

Отредактируйте файл `.env`:

```env
# Telegram Bot Token (получите у @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID канала (начинается с -100)
CHANNEL_ID=-1001234567890

# ID группы (начинается с -100)  
GROUP_ID=-1001234567890

# Optional direct Smule endpoint for the "Песня дня" button
SMULE_PERFORMANCES_URL=

# Optional override for accountId-based Smule API
SMULE_ACCOUNT_ID=

# Optional public profile fallback
SMULE_USERNAME=smule_user

```

### 4. Получение ID канала и группы

#### Для канала:
1. Добавьте бота в канал как администратора
2. Отправьте любое сообщение в канал
3. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. Найдите `"chat":{"id":-1001234567890}` - это ID канала

#### Для группы:
1. Добавьте бота в группу как администратора
2. Отправьте команду `/start` в группе
3. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. Найдите `"chat":{"id":-1001234567890}` - это ID группы

## 📋 Команды бота

### **Основные команды:**
- `/start` - запуск бота и приветствие
- `/help` - список всех доступных команд
- `/hello` - простое приветствие
- `/info` - информация о боте и чате

### **Развлечения:**
- `/prediction` - получить вокальное предсказание
- `/random` - случайная русская песня с Last.fm
- `/cat` - случайное изображение котика
- `/meme` - случайный мем
- `/casino` - игра в слоты с анимацией
- `/pole` - игра "Поле чудес" с голосовыми подсказками
- `/ded` - общий дедометр: каждое новое сообщение со словом «дед» в разрешённых группах добавляет 10%, на 100% дед выдаёт тираду
- `/passport` - постоянный паспорт сквада; также слово «паспорт» в разрешённой группе
- `/order` - постоянный шуточный орден; также слова «орден» и «награда»
- `/guess` - угадай песню по эмодзи за 3 минуты, с подсказкой и кнопкой «Сдаться»
- `/mood` - общее голосование за настроение бота на час
- `/verdict` - голосование «Гей / Негр» за автора команды в разрешённой группе на 5 минут
- `/titles` - общая таблица итогов во всех группах; доступна также в Mini App
- `/ask [вопрос]` - задать вопрос нейросети (Groq; прежний CharacterAI доступен без Groq)
- `/draw [описание]` - создать картинку через Cloudflare Workers AI
- `/transcribe` - расшифровать аудио; в группе отправьте команду ответом на голосовое

### **Зал славы/позора:**
- `/hall [legend/cringe] [имя]` - номинировать пользователя
- `/halllist` - посмотреть списки зала славы/позора
- `/vote [legend/cringe] [имя]` - проголосовать за номинанта

### **Критика и подтверждение:**
- `/roast` - получить критику исполнения (ответом на сообщение)
- `/proof` - подтвердить исполнение (ответом на сообщение)

Бот **умно отвечает** в личных сообщениях на основе ключевых слов:

## Разработка

### Добавление новых команд

Теперь команды вынесены в отдельные файлы! Чтобы добавить новую команду:

1. **Создайте новый файл** в папке `commands/` (например, `commands/mycommand.py`):
```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Команда /mycommand
"""

from telegram import Update
from telegram.ext import ContextTypes

async def mycommand_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """Обработчик команды /mycommand"""
    await update.message.reply_text("Ответ на команду!")
```

2. **Импортируйте команду** в `bot.py`:
```python
from commands.mycommand import mycommand_command
```

3. **Добавьте обработчик** в метод `setup_handlers`:
```python
self.application.add_handler(CommandHandler("mycommand", mycommand_command))
```

### Добавление новых ответов для личных сообщений

Отредактируйте файл `commands/message_handler.py` и добавьте новые условия в функцию `handle_personal_message`.

### Логирование

Бот автоматически логирует все действия. Логи выводятся в консоль с указанием времени, уровня и сообщения.

## Устранение неполадок

### Бот не отвечает на команды

1. Убедитесь, что токен бота правильный
2. Проверьте, что бот добавлен как администратор в канал/группу
3. Убедитесь, что файл `.env` существует и содержит правильные значения

### Кнопка "Песня дня" показывает ошибку 403

Сейчас по умолчанию используется рабочий Smule URL:
`https://www.smule.com/api/profile/performances?accountId=96242367&appUid=sing&offset=0&limit=12`

Если ссылка снова изменится, можно переопределить её через `SMULE_PERFORMANCES_URL` в `.env`. При HTTP 403 или недоступности Smule бот подбирает песню через Last.fm по HTTPS.
Список Last.fm кэшируется на час; при сбое используется последний успешный список,
а если его ещё нет — встроенная подборка с ссылкой на поиск в YouTube. Повторный
запрос к недоступному источнику выполняется не чаще раза в минуту. `LASTFM_API_KEY`
в Secret `env` позволяет задать собственный ключ. Если обложка не отправляется,
бот присылает текст и ссылку на ту же песню.

### Ошибка "BOT_TOKEN не найден"

1. Создайте файл `.env` в корне проекта
2. Добавьте в него строку: `BOT_TOKEN=ваш_токен_здесь`
3. Перезапустите бота

### Зал славы в S3

Helm настроен на бакет `dsipsmule` в `https://nbg1.your-objectstorage.com` (регион
`nbg1`) и объект `dsipsmule-bot/hall/hall.csv`. В существующий Kubernetes Secret
`env` добавьте `S3_ACCESS_KEY_ID` и `S3_SECRET_ACCESS_KEY`, затем обновите релиз.
Ключи в Git не сохраняются. Для локального запуска аналогичные настройки приведены
в `env.example`.

Чтение, номинации и голоса используют S3; при замене Pod они сохраняются.
Первый запуск создаёт отсутствующий объект из локального CSV, сохраняя уже
существующий объект. Успех записи подтверждается после ответа S3. Ошибка доступа
не подменяется пустым списком и не перезаписывает сохранённые данные. Перед первым
обновлением перенесите CSV из старого Pod, если там есть ещё не сохранённые записи.
Подробности: [настройка Helm](helm/smule-bot/README.md).

### Дедометр, паспорта, ордена и настроение

Все пять новых функций доступны в мини-приложении. Дедометр и настроение общие
для всех разрешённых групп; просмотр и голосование доступны также в Mini App.
Один Telegram-пользователь имеет один голос за раунд, даже при голосовании в разных
чатах; повторный выбор меняет голос. Победитель определяет настроение AI-ответов
до окончания часа, затем возвращается основной характер бота.
Доступны 10 настроений: злой дед, после репетиции, Лютик украл микрофон, добрый дед,
бард на бис, романтик у костра, таверна гуляет, вокальный критик, ностальгия по хитам
и ведьмак в дзене. При нажатии кнопки бот обновляет сообщение голосования без новых
сообщений в чат; повторное нажатие той же кнопки не добавляет голос.

Паспорт и орден выдаются один раз по Telegram ID и остаются прежними после смены
ника или редеплоя. Личный чат, разрешённые группы и мини-приложение используют одну
карточку. При отправке от имени канала или анонимного администратора Telegram
передаёт ID канала/группы: для него создаётся отдельная карточка.

В `/guess` отдельный раунд для каждого чата. В группе отправьте название ответом
на загадку или напишите `Ответ: название`; точный правильный ответ принимается и
без префикса. В мини-приложении используйте поле «Название песни». Обычные реплики
в группе не считаются попыткой. Незавершённый раунд можно открыть повторно через
`/guess`, в том числе после перезапуска; время раунда при этом не продлевается.
В каталоге 60 песен: украинские, русскоязычные и зарубежные хиты с подсказками.
Новая загадка не повторяет песню из предыдущего раунда этого чата.

Состояние хранится в том же S3-бакете отдельным объектом
`dsipsmule-bot/fun/state.json` (переопределение: `FUN_S3_KEY`). Существующих S3-ключей
достаточно, если они разрешают чтение и запись этого объекта. Успех выдачи карточки,
голоса и победы подтверждается после записи в S3. При недоступности или повреждении
объекта новые постоянные карточки не выдаются, сохранённые данные не перезаписываются.
Без S3 используется `DATA_DIR/fun.json`; для редеплоя тогда требуется постоянный том.
Используйте одну реплику и стратегию `Recreate`, как в текущем Helm-чарте.

### Гей или негр

Слова «гей», «негр» и их падежные формы (например, «гея», «геем», «негра», «негром»),
в том числе во множественном числе («геи», «геев», «негры», «негров»), запускают
пятиминутное голосование с двумя кнопками **за автора этого сообщения**, даже если
он отвечает другому участнику. Слова распознаются целиком, без учёта регистра.
«Легенда», «легенды» и «зал славы» показывают зал славы; описания после «Нарисуй»
отправляются в генерацию картинки.

Один участник имеет один голос в каждом раунде и может изменить выбор. Повторное
слово от того же автора в том же чате не создаёт второй активный раунд. По окончании
бот обновляет сообщение голосования: убирает кнопки и показывает итог с общей
таблицей «Гей / Негр». При ничьей или отсутствии голосов прежнее звание сохраняется.
Таблица содержит последнее решающее голосование по каждому Telegram ID; более новый
раунд может сменить звание. От имени канала/анонимного админа учитывается ID канала/группы.

Названия вариантов берутся из `CHOICES` в `services/titles.py`. Внутренние ключи
`legend` и `bore` сохранены, поэтому существующие голоса и итоги совместимы.
Голоса, активные раунды и итоги сохраняются в `dsipsmule-bot/fun/state.json` с остальными
развлечениями. После редеплоя бот завершает просроченные раунды и восстанавливает
неотправленные итоги. Если S3 недоступен, успешный голос не подтверждается. В Mini App
раздел «Геи и негры» показывает общие результаты; голосование проходит в группе.
Таблица `/titles` разбивается на сообщения, если участников много.
